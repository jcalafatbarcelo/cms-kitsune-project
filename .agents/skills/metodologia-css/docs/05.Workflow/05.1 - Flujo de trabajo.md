# Flujo de trabajo sugerido

1. Declara las tipografías (si las hay) y las variables globales en `:root`.
2. Define las modificaciones globales de etiquetas (`html`, `body`, `a`, `h1`, `p`…).
3. Define los temas (`t-`), antes que los componentes.
4. Diseña o detecta el bloque base (`c-`) y declara sus variables al inicio
   (`.c-ejemplo, .c-ejemplo * { ... }`).
5. Define variantes (`c--`) solo cuando afectan al bloque completo.
6. Añade elementos (`__`) con semántica clara.
7. Etiqueta estados (`is-`) y añadidos (`has-`).
8. Declara punteros (`js-`) para hooks JavaScript.
9. Añade las media queries de cada bloque justo después de su base, cambiando
   variables cuando baste.
10. Revisa el orden del documento y el [[05.2 - Checklist Implementación|checklist]]
    antes de finalizar.

Detalle del orden y las variables: [[08.1 - Orden y variables]].
