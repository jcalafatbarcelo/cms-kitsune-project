# Accesibilidad WCAG

Accesibilidad como prioridad: todas las soluciones de maquetación deben cumplir **WCAG AA**.

Puntos mínimos
- Semántica correcta en HTML (roles y jerarquías).
- Contraste suficiente y foco visible.
- Estados y mensajes accesibles (no solo color).

Refuerza con la [[05.2 - Checklist Implementación|checklist]] antes de entregar.
