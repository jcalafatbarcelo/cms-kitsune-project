# Diseño escalable

Cualquier propuesta de maquetación debe facilitar su adaptación responsive y su evolución futura.

Recordatorios
- Trabaja mobile-first con valores literales; usa `@custom-media` solo cuando
  PostCSS esté garantizado.
- Evita tamaños rígidos; prefiere unidades relativas y layouts flexibles.
- Documenta variantes y estados para que el componente pueda crecer sin romperse.
