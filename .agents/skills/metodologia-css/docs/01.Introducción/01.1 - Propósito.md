# Propósito de la metodología CSS

Guía base de la metodología CSS (BEM + OOCSS + namespaces).

## Objetivos
- Unificar la semántica de las clases para facilitar mantenimiento y relevo de equipos.
- Reducir redundancias combinando estructura BEM con capas reutilizables OOCSS.
- Centralizar namespaces, estados y convenciones de media queries en un único punto.

## Qué resuelve
- Nombrado predecible de bloques, elementos, variantes y estados.
- Separación clara entre estructura (`c-`) y estilos transversales (`t-`).
- Breakpoints mobile-first con valores literales; `@custom-media` solo cuando
  PostCSS esté garantizado.
- Checklist mínima para asegurar accesibilidad y escalabilidad.
