# Fast Track (6 pasos)

1. Identifica el bloque principal con `c-[bloque]`.
2. Añade elementos dependientes con `c-[bloque]__[elemento]`.
3. Ajusta el bloque completo con `c--[especificacion]`.
4. Usa `is-` para estados temporales y `has-` para contenido extra.
5. Aplica estilos transversales con `t-` (temas reutilizables).
6. Añade `js-` solo para punteros JavaScript (sin estilos).

Mantén esta lista visible mientras maquetas y cruza cada paso con la [[05.2 - Checklist Implementación|checklist completa]].
