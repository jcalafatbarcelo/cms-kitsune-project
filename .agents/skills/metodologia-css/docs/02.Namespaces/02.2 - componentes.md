# Componentes (`c-`)

Convenciones para bloques, elementos y variantes permanentes.

## Bloques y elementos
- Bloque base: `c-[bloque]`.
- Elementos dependientes: `c-[bloque]__[elemento]`.
- Si un elemento empieza a tener demasiadas excepciones, conviértelo en un bloque propio.

```html
<div class="c-slider">
  <div class="c-slider__item c-ficha">
    <p class="c-ficha__text">Contenido</p>
  </div>
</div>
```

```css
.c-slider { /* Estilos genéricos del slider */ }
.c-slider__item { /* Elementos dentro del slider */ }

.c-ficha { /* Bloque reutilizable */ }
.c-ficha__text { /* Elemento dependiente del bloque ficha */ }
```

## Variantes (`c--`)
- Representan especificaciones estables del bloque completo.
- Siempre se escriben junto a la clase base: `.c-bloque.c--variante { ... }`.

```html
<div class="c-slider c--deportes">
  <div class="c-slider__item">…</div>
</div>
```

```css
.c-slider { /* Base */ }
.c-slider.c--deportes { /* Ajustes de la variante deportes */ }
```
