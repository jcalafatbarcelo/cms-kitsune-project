# Hooks JavaScript (`js-`)

- Prefijo exclusivo para punteros de comportamiento (no llevan estilos CSS).
- Añádelo junto a la clase del bloque: `.c-slider.js-slider`.
- Facilita buscar nodos en tests o scripts sin depender de estilos.

```html
<div class="c-slider c--deportes js-slider">
  <div class="c-slider__item">…</div>
</div>
```

```javascript
const slider = document.querySelector('.js-slider');
// slider.classList.add('is-ready');
```

Recuerda: si el comportamiento cambia el estado visual, combínalo con `is-` ([[02.3 - estados]]).
