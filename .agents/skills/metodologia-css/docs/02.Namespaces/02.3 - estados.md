# Estados y contenidos opcionales

## `is-` vs `c--`
- `is-` describe un estado temporal (activo, deshabilitado, destacado).
- `c--` redefine el bloque completo como variante estable (por ejemplo, slider de deportes).
- Si el cambio afecta a todos los elementos internos de forma permanente, usa `c--`.
- Si el cambio es puntual o depende de lógica/JS, usa `is-`.

```html
<div class="c-ficha is-destacado">…</div>
<div class="c-ficha c--promo">…</div>
```

## `has-` vs `c--`
- `has-` indica que el componente incluye un sub-elemento opcional (imagen, icono, badge).
- Evita `c--` cuando solo un descendiente requiere ajustes por la presencia de ese sub-elemento.

```html
<div class="c-ficha has-picture">
  <picture class="c-ficha__picture"></picture>
</div>
```

## Buenas prácticas
- Los estados (`is-`) y contenidos (`has-`) no sustituyen a la variante base: se suman sobre la clase `c-`.
- No mezcles estilos de temas con estados; los temas son transversales (ver [[02.4 - temas]]).
- Para estados controlados con JavaScript, combina `js-` y `is-` (`.js-modal.is-open`).
