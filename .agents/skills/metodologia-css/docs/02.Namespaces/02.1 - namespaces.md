# Guía de namespaces

Prefijos oficiales de la metodología. Úsalos para comunicar propósito desde el nombre.

| Namespace | Uso principal | Ejemplos |
|-----------|---------------|----------|
| `c-`      | Componentes (bloques base) | `c-slider`, `c-ficha` |
| `c__`     | Elementos dependientes del bloque | `c-slider__item`, `c-ficha__text` |
| `c--`     | Especificaciones/variantes del bloque completo | `c--deportes`, `c--adoptado` |
| `t-`      | Temas o estilos transversales | `t-especial`, `t-warning` |
| `js-`     | Punteros para scripts (no se estilizan) | `js-slider` |
| `is-`     | Estado temporal del objeto | `is-destacado`, `is-disabled` |
| `has-`    | Mismo objeto con contenido extra | `has-picture`, `has-icon` |
| `a-`      | Nombres de animaciones declaradas en CSS | `a-fade-in`, `a-slide` |

Notas rápidas:
- Usa `is-` para cambios temporales; si la variación es estable del bloque completo, prefiere `c--`.
- Usa `has-` cuando solo un descendiente cambia por contenido opcional; si afecta a todo el bloque, sube a `c--`.
- `js-` jamás lleva estilos; es un hook de comportamiento.
