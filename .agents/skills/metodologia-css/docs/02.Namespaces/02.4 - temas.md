# Temas y animaciones

## Temas (`t-`)
- Estilos transversales aplicables a cualquier componente.
- No dependen de la estructura interna del bloque.
- Usalos para color, tipografia, espaciados o mensajes que se repiten.

```html
<p class="c-ficha__text t-especial">Texto destacado</p>
<span class="t-warning">Warning message</span>
```

## Animaciones (`a-`)
- Prefijo reservado para nombres de animaciones declaradas en CSS (`animation-name`).
- Mantiene consistente el naming de efectos.

```css
@keyframes a-fade-in {
  from { opacity: 0; }
  to { opacity: 1; }
}

.c-ficha { animation: a-fade-in 160ms ease; }
```

### Guia rapida para `a-`
- Usalo solo para nombrar `@keyframes` y `animation-name`; la activacion va con clases existentes (`is-`, `c--`, `t-`), no con clases `a-`.
- Reutiliza el mismo nombre `a-` en todos los sitios donde se declare o use la animacion; evita duplicar efectos con nombres distintos.
- Documenta duracion y timing si no son obvios; ejemplo: `animation: a-fade-in 160ms ease-out;`.

### Ejemplo combinando `a-` + `is-`
```html
<button class="c-button js-button">
  <span class="c-button__label">Guardar</span>
</button>
```

```css
@keyframes a-pulse {
  from { transform: scale(1); }
  50% { transform: scale(1.02); }
  to { transform: scale(1); }
}

.c-button.is-processing {
  animation: a-pulse 600ms ease-in-out infinite;
}

@media (prefers-reduced-motion: reduce) {
  .c-button.is-processing {
    animation: none;
  }
}
```

```javascript
const button = document.querySelector('.js-button');
button.addEventListener('click', () => {
  button.classList.add('is-processing');
  setTimeout(() => button.classList.remove('is-processing'), 1200);
});
```
