# Ejemplos practicos

Espacio para documentar componentes reales aplicando la metodologia.

Sugerencia de formato por componente:
1) Contexto y objetivo.
2) HTML minimo con clases `c-`, `__`, `--`, `is-`, `has-`, `t-`, `js-` si aplica.
3) CSS base, variantes y estados (respetando el orden del documento: ver [[08.1 - Orden y variables]]).
4) Notas responsive indicando breakpoints usados.
5) Checklist rapida (accesibilidad y escalabilidad).

## Ejemplo base
```html
<div class="c-slider c--deportes js-slider">
  <div class="c-slider__item c-ficha has-picture">
    <picture class="c-ficha__picture"></picture>
    <p class="c-ficha__text t-especial">Lorem Ipsum</p>
  </div>

  <div class="c-slider__item c-ficha is-destacado">
    <p class="c-ficha__text t-especial">Lorem Ipsum</p>
  </div>
</div>
```

```css
/* --- Temas (t-): antes que los componentes --- */
.t-especial { color: #1f5fbf; }

/* --- Componentes (c-) --- */
.c-slider,
.c-slider * {
  --c-slider-gap: 1rem;
}

.c-slider { /* Base */ }
.c-slider.c--deportes { /* Variante estable */ }
.c-slider__item { /* Elementos internos */ }

.c-ficha,
.c-ficha * {
  --c-ficha-radio: 12px;
}

.c-ficha { /* Bloque reutilizable */ }
.c-ficha.has-picture { /* Ajustes por contenido opcional */ }
.c-ficha.is-destacado { /* Estado puntual */ }

/* Media de c-ficha, justo después de su base */
@media (min-width: 768px) {
  .c-ficha,
  .c-ficha * {
    --c-ficha-radio: 16px;
  }
}
```

## Ejemplo: animaciones con prefijo `a-` + estado `is-`
Contexto: animar un hero con tarjetas usando nombres de animacion `a-` y activacion via estado `is-`.

```html
<section class="c-hero js-hero">
  <h1 class="c-hero__title">Titular animado</h1>
  <p class="c-hero__text">Texto descriptivo.</p>

  <div class="c-hero__cards">
    <article class="c-card has-picture">
      <picture class="c-card__picture"><img src="..." alt="" /></picture>
      <h3 class="c-card__title">Card 1</h3>
    </article>
    <article class="c-card has-picture">
      <picture class="c-card__picture"><img src="..." alt="" /></picture>
      <h3 class="c-card__title">Card 2</h3>
    </article>
    <article class="c-card has-picture">
      <picture class="c-card__picture"><img src="..." alt="" /></picture>
      <h3 class="c-card__title">Card 3</h3>
    </article>
  </div>
</section>
```

```css
/* Keyframes con prefijo a- */
@keyframes a-slide-title {
  0% { transform: translateY(200px); opacity: 0; }
  50% { opacity: 0.2; }
  100% { transform: translateY(0); opacity: 1; }
}

@keyframes a-slide-in {
  0% { transform: translateY(200px); opacity: 0; }
  50% { opacity: 0.3; }
  100% { transform: translateY(0); opacity: 1; }
}

@keyframes a-cards-in {
  0% { transform: translateY(50px); opacity: 0; }
  100% { transform: translateY(0); opacity: 1; }
}

@keyframes a-picture-in {
  0% { transform: scale(1.2); }
  100% { transform: scale(1); }
}

.c-hero {
  --anim-time: 0.5s;
  --anim-ease: ease-out;
  --anim-delay: 0s;
}

/* Estado que activa las animaciones */
.c-hero.is-animated .c-hero__title {
  animation: a-slide-title var(--anim-time) cubic-bezier(0, 0.7, 0.14, 0.98);
}

.c-hero.is-animated .c-hero__text {
  animation: a-slide-in var(--anim-time) var(--anim-ease) var(--anim-delay) both;
}

.c-hero__cards {
  display: grid;
  gap: 1rem;
}

.c-hero.is-animated .c-card {
  animation: a-cards-in var(--anim-time) var(--anim-ease) both;
}

.c-hero.is-animated .c-card:nth-child(2) { animation-delay: 0.25s; }
.c-hero.is-animated .c-card:nth-child(3) { animation-delay: 0.5s; }

.c-card__picture {
  display: block;
  overflow: hidden;
}

.c-card__picture img {
  display: block;
  width: 100%;
}

.c-hero.is-animated .c-card__picture img {
  animation: a-picture-in var(--anim-time) var(--anim-ease) both;
}

/* Media del componente, justo después de su base */
@media (max-width: 767px) {
  /* En mobile quitamos los retardos para que todo entre a la vez */
  .c-hero.is-animated .c-card:nth-child(n) { animation-delay: 0s; }
}

@media (prefers-reduced-motion: reduce) {
  .c-hero.is-animated .c-hero__title,
  .c-hero.is-animated .c-hero__text,
  .c-hero.is-animated .c-card,
  .c-hero.is-animated .c-card__picture img {
    animation: none;
  }
}
```

```javascript
const hero = document.querySelector('.js-hero');
if (hero) {
  // Activa las animaciones al siguiente frame (evita que se apliquen en carga sin transicion)
  requestAnimationFrame(() => hero.classList.add('is-animated'));
}
```

Notas:
- Los nombres de animacion usan prefijo `a-`; la activacion se controla con el estado `is-animated` en el bloque.
- Prefiere propiedades transform/opacity para mejor rendimiento; evita animar top/left.
- Ajusta los retardos con variables o nth-child segun el numero de elementos.
- Respeta `prefers-reduced-motion`: el estado final se conserva sin reproducir animaciones.
