# Nomenclatura de sufijos responsive

Estructura sugerida: `[condicion][tamano][rango]`

- Condiciones: `n` (no), `o` (solo), `c` (custom).
- Tamaños opcionales: `s` (small), `x` (extra).
- Rango base: `sm`, `m`, `t`, `nt`, `d1`, `d2`, `d3`, `xl`.

Ejemplos
- `.c-card-nm` → estilos aplicables a todo lo que no sea mobile (`@media (min-width: 768px)`).
- `.c-slider-od2` → override que solo vive en `@media (min-width: 1360px) and (max-width: 1599px)`.

Relaciona estos sufijos con los tokens definidos en [[04.1 - Tokens Custom Media]] y la [[04.2 - Tabla equivalencias]].
