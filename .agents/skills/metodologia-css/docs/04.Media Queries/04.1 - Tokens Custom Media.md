# Breakpoints y `@custom-media`

## Uso por defecto: valores literales

Por norma general **no se usa `@custom-media`**: los proyectos no disponen de
PostCSS y el navegador no lo interpreta. Declara los breakpoints con valores
literales (`px`) según la [[04.2 - Tabla equivalencias|tabla de equivalencias]].

```css
@media (min-width: 768px) {
  /* Ajustes responsive para no-mobile */
}
```

## Uso condicional de `@custom-media`

Usa `@custom-media` **solo cuando esté garantizada la disponibilidad de
PostCSS** (por ejemplo `postcss-custom-media`). Si no puedes confirmarlo, usa el
valor literal.

```css
@custom-media --bp-nm (min-width: 768px);

@media (--bp-nm) {
  /* Ajustes responsive para no-mobile */
}
```

Tokens disponibles (solo con PostCSS):

```css
@custom-media --bp-sm (max-width: 399px);
@custom-media --bp-m (max-width: 767px);
@custom-media --bp-t (min-width: 768px) and (max-width: 1023px);
@custom-media --bp-nm (min-width: 768px);
@custom-media --bp-nt (min-width: 1024px);
@custom-media --bp-d1 (min-width: 1024px) and (max-width: 1359px);
@custom-media --bp-d2 (min-width: 1360px) and (max-width: 1599px);
@custom-media --bp-d3 (min-width: 1600px) and (max-width: 1919px);
@custom-media --bp-xl (min-width: 1920px);
/* Opcionales: --bp-om/--bp-ot/... para rangos solo; --bp-c-* para medias custom */
```

## Orden de las media queries

Las media queries van **inmediatamente después** de las reglas sin media de su
bloque base (tema o componente), no agrupadas al final del archivo. Esta
organización no cambia la especificidad, pero puede cambiar el orden de origen
entre reglas de igual especificidad. Conserva el orden global desde componentes
genéricos a especializados; por ejemplo, `c-textofoto` antes de `c-textblock`.
Ver [[08.1 - Orden y variables]].

```css
.c-ficha { border-radius: 12px; }

@media (min-width: 768px) {
  .c-ficha { border-radius: 8px; }
}

@media (min-width: 1360px) {
  .c-ficha { border-radius: 16px; }
}
```

Ver también [[04.2 - Tabla equivalencias]], [[04.3 - Nomenclatura Sufijos]].
