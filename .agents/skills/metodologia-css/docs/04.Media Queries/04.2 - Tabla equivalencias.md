# Tabla de equivalencias de breakpoints

Referencia de rangos. Por defecto se usan los **valores literales de la columna
"Media query"** (ver [[04.1 - Tokens Custom Media]]); la columna del token
`@custom-media` solo aplica cuando hay PostCSS garantizado.

| Token `@custom-media` | Sufijo | Media query | Uso recomendado |
|-----------------------|--------|-------------|-----------------|
| `--bp-sm`             | `-sm`  | `@media (max-width: 399px)` | Mobile muy pequeño |
| `--bp-m`              | `-m`   | `@media (max-width: 767px)` | Mobile general |
| `--bp-t`              | `-t`   | `@media (min-width: 768px) and (max-width: 1023px)` | Tablet |
| `--bp-nm`             | `-nm`  | `@media (min-width: 768px)` | No mobile |
| `--bp-nt`             | `-nt`  | `@media (min-width: 1024px)` | No tablet (desktop base) |
| `--bp-d1`             | `-d1`  | `@media (min-width: 1024px) and (max-width: 1359px)` | Desktop compacto |
| `--bp-d2`             | `-d2`  | `@media (min-width: 1360px) and (max-width: 1599px)` | Laptop grande / 1440px |
| `--bp-d3`             | `-d3`  | `@media (min-width: 1600px) and (max-width: 1919px)` | Desktop ancho |
| `--bp-xl`             | `-xl`  | `@media (min-width: 1920px)` | Ultra ancho / 4K inicial |
| `--bp-om`, `--bp-ot`, etc. | `-om`, `-ot`, ... | `@media only (rango)` | Overrides exclusivos |
| `--bp-c-*`            | `-c*`  | `@media (custom)` | Rangos específicos por componente |

Usa la tabla junto con los sufijos de [[04.3 - Nomenclatura Sufijos]].
