# Reglas clave

- Las especificaciones (`c--x`) siempre se escriben junto al bloque: `.c-ficha.c--promo { ... }`.
- Componentes anidados repiten ambas clases cuando corresponde: `class="c-padre__hijo c-hijo"`.
- Si un hijo necesita demasiadas excepciones dentro de un bloque, conviértelo en bloque independiente.
- Los temas (`.t-`) van **siempre antes** de los componentes (`.c-`).
- Cada media query va **después** del bloque base (tema o componente) al que afecta.
- Orden del documento: tipografías → `:root` → etiquetas → temas → componentes.
